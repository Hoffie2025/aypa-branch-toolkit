# AYPA Branch Toolkit

This project is a simple React application intended as a starting point for a youth church management dashboard. It was created using `react-scripts` and can be deployed on Vercel.

## Project Structure

- `public/index.html` – The HTML template used by React.
- `src/index.js` – Entry point that renders the React application.
- `src/App.js` – Main application component.
- `src/components/MemberList.js` – Example component listing youth members.

## Running Locally

1. Ensure you have [Node.js](https://nodejs.org/) installed.
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm start
   ```
   The app will be available at `http://localhost:3000`.

## Building for Production

To create an optimized build that can be deployed (for example to Vercel):
```bash
npm run build
```
The build output will be created in the `build/` directory.
